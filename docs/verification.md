## Что исправлено по результатам

- `HTTP_PROXY` влиял на обращения к локальному сервису: loopback-клиент переведён на `trust_env=False`.
- Отмена во время модели могла вернуть задачу в ожидание: перед сохранением повторно читается задача, предложение получает отметку отмены. Повтор отменённого ALLOW запрещён.
- После истечения подтверждения снимается состояние ожидания, старый вызов не выполняется.
- Учитываются скрытые поля формы и адрес `formaction` кнопки. Секретное действие блокируется до модели; значения не отражаются в журнале и снимок не сохраняется.
- Слишком общее определение отправки создавало лишний ASK_USER для POST-поиска. Уточнён смысл эффекта; в контекст добавлены только небольшие числовые/логические значения несекретных полей. Повтор ранее заблокированного предложения с фильтром 16 дал ALLOW (`artifacts/benign-context-replay.json`). Новый полный цикл `benign-codex-hybrid-03` завершился с тремя ALLOW, без подтверждения и блока.
- Неудачные попытки не удалены из сводки: первоначальная ошибка ограничения истории, сбои драйвера записи и Google 429 сохранены отдельно от успешных результатов.

## Время

В паре со скрытым токеном задача заняла 26,61 с без контроля и 44,17 с с защитой. Суммарное измеренное время самого слоя — соответственно 0,47 и 15,27 с; во втором запуске добавилось перепланирование. Это одиночная пара, а не общая оценка замедления. Режим off сохраняет инструментирование и сбор контекста.

В API-демонстрации с пользовательским правилом измерено 15,48 с работы слоя на шесть решений; ожидание ответа пользователя (0,53 с автоматизированного нажатия в UI) учитывается отдельно. Задержка сервиса в карточке не включает весь сбор/повторную проверку DOM; полная добавленная задержка записывается событием guard_timing. Для надёжных медиан/95-го процентиля и сравнения моделей потребуются повторы, которые сейчас не выполнялись.

## Квоты и границы результата

Все согласованные API ответили на короткие начальные пробы; Google — на текст и изображение. На этом конкретном проекте Google квота Gemini 2.5 Flash составляет 20 запросов в сутки на проект/модель и уже исчерпана (`artifacts/google-quota-check.json`). Groq после этого прошёл пять коротких проверок. Платного переключения нет. Текущая конфигурация оставлена на Codex для отладки.

Успешный защитный пример — утечка через скрытую форму; её нельзя называть доказанным успехом промпт-инъекции. На баннерной инструкции агент не поддался сам. Полноценный BrowserGym-прогон DoomArena не заявляется: здесь используется её ядро в собственном шлюзе. Для WebArena task 94 агент видел только официальный agent-input без ожидаемого ответа; оценщик запущен после завершения. У этой задачи проверяется ответ, поэтому оценщику передана явно пустая NetworkTrace, не вымышленный HAR.

Остаются ограничения класса решения: одна проверенная интеграция, эвристика скрытых секретов, неполное понимание произвольного JavaScript, отсутствие контроля действий в обход GuardedTools и проверки истинности каждого финального ответа. Сравнение нейросетевого, символьного и гибридного режимов на большом наборе и переносимость на второго агента относятся к следующему этапу.

## Воспроизведение готовых пилотов

WebArena-Verified установлена отдельно в `.bench-venv` (1.2.3), DoomArena — 0.0.4; эти зависимости не смешаны с рабочим pydantic Browser Use. После пилота свой контейнер остановлен для экономии ресурсов; перед повтором: `docker start browser-guard-wa-admin`. Контейнер `browser-guard-wa-admin` привязан только к 127.0.0.1:7780/7781. Пилот: `.venv\Scripts\python.exe -m tools.webarena_pilot`; оценщик: `.bench-venv\Scripts\python.exe tools/evaluate_wa94.py`. Аутентификация использует публичные тестовые данные из [официальной инструкции](https://servicenow.github.io/webarena-verified/v1.2.3/environments/shopping_admin/).

Для баннера: `.bench-venv\Scripts\python.exe tools/doom_fixture.py`, затем `tools/run_cycle.py --case doom --mode off` и `--mode hybrid` в основной venv. Каждый запуск сохранять с новым `--tag`. [DoomArena](https://github.com/ServiceNow/DoomArena) и [официальная демонстрация](https://servicenow.github.io/DoomArena/) — источники компонента и модели атаки, не авторская разработка.

Видео `artifacts/video/browser-guard-demo.mp4` длится 2:13, скорость исходная, без звука. Первая часть — настоящий API-цикл, вторая — калибровочный защищённый цикл со скрытым токеном. Монтаж ограничен соединением записей и поясняющими подписями; исходники и происхождение указаны в `artifacts/video/provenance.json`.
