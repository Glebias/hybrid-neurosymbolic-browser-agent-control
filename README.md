# Browser Guard

Курсовой проект: гибридная нейросимвольная система контроля действий браузерных интеллектуальных агентов.

Платформа запускает **Browser Use 0.13.14** с встроенным `GuardedTools`, проверяет предложение до исходного `Tools.act` и показывает ход задачи в локальном интерфейсе. Стек: Python/FastAPI, SQLite, React/TypeScript/Vite. Репозиторий локальный; публикация не настроена.

## Установка на Windows

Проверенная среда: Python 3.13, Node.js 25, установленный Google Chrome. Короткий путь `C:\src\browser-guard` выбран вне OneDrive; рекурсивные подмодули не используются.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
Copy-Item .env.example .env
```

В `.env` задайте `MODEL_PROVIDER`, `MODEL_BASE_URL`, `MODEL_API_KEY`, `AGENT_MODEL`, `GUARD_MODEL`. Поддерживается совместимый с chat-completions API и прямой API Anthropic. Для Anthropic укажите `MODEL_PROVIDER=anthropic` и базу `https://api.anthropic.com/v1`. Выбирайте модели с поддержкой структурированного ответа и изображений. Сервис не показывает ключ в UI и не хранит его в SQLite. API вызывается с содержимым ограниченного контекста страницы; используйте учебные данные до оценки конфиденциальности своего сценария.

```powershell
.\start.ps1
```

Откройте <http://127.0.0.1:8765>. Первая кнопка примера заполняет задачу на поиск. Вторая — заявку, отправка которой требует подтверждения. Примеры работают с изолированной страницей `/lab`; это **не WebArena и не доказательство устойчивости к произвольным сайтам**.

## Как устроено подключение

`guard/runner.py` получает задачу сервиса и создаёт `Agent(task=..., tools=GuardedTools(...), browser=...)`. `guard/integration.py` переопределяет `Tools.act`, получает наблюдение из **той же BrowserSession**, отправляет `Action` в `/api/decide`, удерживает вызов при `ASK_USER` и вызывает исходный метод только после разрешения. Отдельного наблюдателя, CDP-прокси и системного фильтра нет.

Перед исполнением повторно проверяются статус задачи, версия политики, адрес и целевой элемент. Отказ возвращается через `ActionResult(error=...)`, чтобы агент мог перепланировать. Повтор HTTP-запроса не даёт повторного исполнения. Отмена задачи не откатывает уже выполненное действие. Закрытые агенты и вызовы в обход `GuardedTools` не покрываются.

Контекст: прямая цель, фактический инструмент и параметры, адрес и целевой элемент, до 12000 знаков наблюдения, до пяти последних действий, при необходимости снимок страницы. Содержимое страницы недоверенное. Модель даёт типизированную оценку, окончательный исход формируют правила. Полный набор файловых инструментов и `evaluate` исключён из защищённого агента.

## Проверка

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe tools/ui_smoke.py
.venv\Scripts\python.exe -m tools.browser_smoke
```

Для двух последних команд сервис должен работать. `ui_smoke` проверяет настоящий собранный интерфейс и API, сохраняет снимки и JSON. `browser_smoke` использует настоящий Chrome и исполнитель Browser Use, но **тестовый анализатор вместо облачной модели**; его результат нельзя называть полноценным агентским экспериментом. Компонентные тесты также используют контролируемые ответы анализатора и spy исполнителя.

Все данные запусков, снимки и профили находятся в `.data/` и исключены из Git. Проверки и их ограничения записываются в `docs/progress.md`, итоговые материалы — в `artifacts/`. Полноценный агентский прогон, сравнительные бенчмарки и видеозапись проверяются отдельно после подключения реального API.

## Структура

- `guard/` — сервер, форматы, база, анализатор, правила, интеграция и запуск.
- `frontend/` — интерфейс, версии зависимостей в `package-lock.json`.
- `demo/` — воспроизводимая учебная страница, без платежей и реальных отправок.
- `tests/`, `tools/` — тесты и инструменты проверки/экспорта.
- `docs/`, `artifacts/` — журнал разработки и проверяемые результаты.

Основные источники интерфейсов: [Browser Use Tools](https://docs.browser-use.com/open-source/customize/tools/add), [Agent parameters](https://docs.browser-use.com/open-source/customize/agent/all-parameters). Сам Browser Use установлен как внешняя зависимость; его исходный код не выдаётся за авторскую разработку.
